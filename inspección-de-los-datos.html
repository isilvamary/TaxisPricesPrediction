El análisis de la estructura mediante str(datos) permite identificar el tipo de dato asignado a cada variable.

Las variables relacionadas con distancias, tarifas, duración, número de pasajeros y precio son de naturaleza cuantitativa, mientras que las variables relacionadas con las condiciones del viaje, como el momento del día, el día de la semana, el tráfico y el clima, son categóricas.

Esta clasificación es importante porque determina qué métodos estadísticos pueden utilizarse posteriormente. Por ejemplo, las variables cuantitativas pueden analizarse mediante medidas como la media, mediana y desviación estándar, mientras que las variables categóricas pueden estudiarse mediante frecuencias y proporciones.

La función summary() proporciona una primera descripción estadística de las variables.

Para las variables cuantitativas, el resumen incluye valores como:

mínimo, primer cuartil, mediana, media, tercer cuartil, máximo.

Estos estadísticos permiten conocer la posición y dispersión de los datos y realizar una primera evaluación de sus distribuciones.

Por ejemplo, la comparación entre la media y la mediana puede proporcionar indicios sobre la simetría de una variable. Si ambas son similares, la distribución puede ser aproximadamente simétrica; mientras que diferencias importantes pueden sugerir asimetría o la presencia de valores extremos.

En las variables categóricas, summary() permite observar las frecuencias de las diferentes categorías, lo cual ayuda a identificar cuáles son las condiciones más frecuentes dentro de los viajes estudiados.

Inicialmente se realizó un conteo de los valores faltantes mediante:

colSums(is.na(datos))

Este procedimiento permitió identificar la presencia de datos faltantes en las variables de la base.

Los valores faltantes constituyen un aspecto importante del análisis, ya que pueden reducir el tamaño efectivo de la muestra y afectar algunos procedimientos estadísticos si no son tratados adecuadamente.

Por esta razón, se decidió realizar un proceso de imputación.

Notamos que existen datos faltantes en todas las variables, tanto categóricas como numéricas.

Para las variables cuantitativas se utilizó la mediana como medida de imputación.

La mediana corresponde al valor que divide los datos ordenados en dos partes iguales. Se escogió esta medida debido a que presenta una menor sensibilidad frente a valores extremos en comparación con la media.

El procedimiento reemplaza cada valor faltante por la mediana calculada utilizando los valores observados de la misma variable. De esta manera, se conserva el número total de observaciones de la base. Es decir, estamos haciendo una estimación sencilla para poder continuar con el análisis.

verificamos que las variables numéricas que fueron remplazadas por la mediana y luego los valores faltantes de las categóricas por la moda

# Imputación de variables numéricas con la mediana
datos[sapply(datos, is.numeric)] <- lapply(
  datos[sapply(datos, is.numeric)],
  function(x) replace(x, is.na(x), median(x, na.rm = TRUE))
)

# Función para calcular la moda
moda <- function(x) {
  x <- x[!is.na(x)]
  ux <- unique(x)
  ux[which.max(tabulate(match(x, ux)))]
}

# Imputación de variables categóricas con la moda
datos[sapply(datos, is.character)] <- lapply(
  datos[sapply(datos, is.character)],
  function(x) replace(x, is.na(x), moda(x))
)

# Comprobar valores faltantes

con el objetivo de verificar la efectividad del procedimiento de imputación. Al obtener 0 en todas las variables, significa que no quedaron valores NA en la base de datos después de la imputación.

Esto permite continuar con el análisis exploratorio sin perder observaciones debido a datos faltantes.
